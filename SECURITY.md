# Security Policy

## Supported Versions

The latest commit on `main` is the supported version. Blogsmith is a
self-hosted MVP; there are no released version lines to patch.

## Reporting a Vulnerability

Please use GitHub's private vulnerability reporting (Security tab ->
"Report a vulnerability") instead of opening a public issue. Include the
affected endpoint or file, a reproduction, and the impact. You can expect an
acknowledgement within a few days.

Please do not test against deployments you do not own.
