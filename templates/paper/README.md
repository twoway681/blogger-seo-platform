# Paper

Quiet serif on a warm paper background. For long-form writing, essays and book blogs.

- Zero JavaScript, zero external requests, system serif stack (Georgia et al.)
- Narrow ~40rem measure, 1.7 line height, italic bylines
- Accent color editable in Blogger's Theme Designer

## Install

1. Download `theme.xml` from this folder (on GitHub: open it and click the download/raw button).
2. Blogger dashboard: **Theme > arrow next to Customize > Download** to back up your current theme.
3. **Theme > arrow next to Customize > Restore** and upload the downloaded `theme.xml`.
4. Check your home page, one post, and one label page on your phone.

## After install

- Turn on **Settings > Meta tags > Search description** and fill it per post.
- Set **Posts per page** to 5-7; Paper is built for long reads.
