# Mono

Terminal-inspired theme with automatic dark mode (follows the reader's OS setting). For tech and programming blogs.

- Zero JavaScript, zero external requests, system fonts with monospace accents
- `prefers-color-scheme` dark mode, `color-scheme` aware form controls
- Styled inline code and code blocks out of the box
- Accent color editable in Blogger's Theme Designer (applies to light mode; dark mode uses its own green)

## Install

1. Download `theme.xml` from this folder (on GitHub: open it and click the download/raw button).
2. Blogger dashboard: **Theme > arrow next to Customize > Download** to back up your current theme.
3. **Theme > arrow next to Customize > Restore** and upload the downloaded `theme.xml`.
4. Check your home page, one post, and one label page on your phone - and once more with dark mode on.

## After install

- Turn on **Settings > Meta tags > Search description** and fill it per post.
- Set **Posts per page** to 7-10.
